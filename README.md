# \# Projecte JOVECO

# 

# Aquest repositori forma part del projecte final del cicle de \*\*Sistemes Microinformàtics i Xarxes (SMX)\*\*, realitzat durant el curs \*\*2025-2026\*\*.

# 

# L’autor del projecte és \*\*Adrià Cabrera Martínez\*\*.

# 

# \## Descripció del projecte

# 

# JOVECO és un projecte orientat a la modernització d’un supermercat, combinant una part de presència web, una botiga online, un sistema de gestió interna i una proposta d’infraestructura de xarxa.

# 

# L’objectiu principal és plantejar una solució informàtica que permeti millorar la gestió del negoci, controlar millor els productes i l’estoc, preparar comandes online i tenir una base tècnica més organitzada.

#

#
